# 노출 다이얼 하네스

개인 장기 투자자의 투자 모델 시험장. 매일 미국장 마감 뒤(한국 07:00) 다이얼을 계산해 기록을 쌓고, 방향이 맞는지 4주 단위로 채점한다. 매매 권유가 아니다.

- 다이얼 = 추세(금요일 주봉 종가 > 30주선 ? 1 : 0) × min(1, 30% ÷ 최근 20거래일 변동성)
- 종목 비중 한도 = min(시장 QQQ 다이얼, 종목 다이얼). 줄임은 매일, 늘림은 금요일 종가 뒤.
- 손절 = 진입가 −7.5%, 한 번에 거는 손실 = 총자금 1.5%.
- 파일: `dial_core.py`(계산) · `run.py`(자동 실행) · `dial.json`(오늘 값) · `dial_history.csv`(기록) · `holdings.json`(진입가)
